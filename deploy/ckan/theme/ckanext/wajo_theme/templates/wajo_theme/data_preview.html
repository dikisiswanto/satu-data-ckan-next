    Alur setelah ini aktif

    1. Admin mengunggah CSV/Excel ke sumber daya.
    2. CKAN otomatis mengirim sumber daya ke antrean XLoader.
    3. Proses pekerja memuat tabel ke DataStore.
    4. Detail dataset menampilkan pratinjau dan API.
    5. Portal publik menerima invalidasi cache setelah pemuatan selesai.

    Format pratinjau tabular

    CSVTSVXLSXLSXODS

    Format lain tetap dapat diunduh sebagai berkas, tetapi tidak otomatis menjadi tabel DataStore.

    Perlu bantuan?

    Jika sumber daya tetap menunggu, periksa status antrean, log proses pekerja, format berkas, token internal, dan izin database.
